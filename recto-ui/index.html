How it works.

  1. Connect your site.WordPress Application Password or Webflow API key.
  2. Connect Google Search Console.Optional, but it ranks the orphans by traffic.
  3. Read the site.One pass, up to 10,000 pages.
  4. Surface the orphans.Ranked list, top of the page is the most valuable.
  5. Insert the link.Pick a candidate paragraph. recto pushes through the CMS API.
  6. Re-read on a schedule.Weekly by default. New orphans surface as you publish.
