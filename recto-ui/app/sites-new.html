Application Password is the WordPress-recommended way. Takes 60 seconds. Walk-through below.

Walk-through
  1. In wp-admin, open Users → Profile.
  2. Scroll to Application Passwords, type the name recto, click Add New.
  3. Copy the generated password (24 characters with spaces) and paste it into the field above.

If you do not see Application Passwords, your host has disabled them. Use the JWT fallback (Settings → Integrations once connected).
